# pi-subagents

Pin: `npm:pi-subagents` in source `settings.json`. Upstream: <https://github.com/nicobailon/pi-subagents> Landing: [SPEC.md](./SPEC.md). Machine: [sidecars.json](./sidecars.json). Install: [guides/install-packages.md](../../guides/install-packages.md).
